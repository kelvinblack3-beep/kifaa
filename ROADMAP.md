# Roadmap — KIFAA

Milestone 1 (Repository baseline)
- Initialize project memory and documentation (this commit)
- Verify ledger implementation and tests
- Scaffold shared packages and adapter interfaces
- Implement sandbox provider adapters and sample flows

Milestone 2 (Core orchestration)
- Implement transaction engine and routing
- Implement database schema and migrations (Drizzle)
- CI pipeline: typecheck, tests, build

Milestone 3 (Provider integration & compliance)
- Provider onboarding (sandbox → production gating)
- AML/KYC workflows and compliance program
- Security review and penetration testing

Milestone 4 (Production readiness)
- Provider contracts and regulator confirmation
- Live payment processing under legal approvals
- Scaling and operations
