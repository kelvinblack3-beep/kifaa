# KIFAA-SC/research — README

This directory stores experiment artifacts, benchmarks, and research notebooks for KIFAA-SC. Examples:
- benchmark results for Ollama on candidate SOMs
- kernel/runtime configuration snippets
- experiment notes and raw logs

Recording rules:
- Every artifact MUST reference the repository commit or a durable URL and an entry in RESEARCH_LOG.md.
- Use descriptive filenames and dates.
